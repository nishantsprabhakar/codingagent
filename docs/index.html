// SIGN IN TO CONTINUE

This is a browser-only chat demo of Wrexlyn — sign in, then bring your own API key for whichever provider you like, and talk to the model. It has no file or shell tools; that's what the local desktop app is for — a static page genuinely can't run code on your machine.

Sign-in runs entirely in your browser (Google Identity Services) — nothing about who you are is sent to or stored on any server. It's just used to show your name here for this session.

// SET UP YOUR PROVIDER

Pick a provider and paste in your own free API key — Groq takes about a minute, no credit card. It's saved only in this browser's local storage and sent directly from your browser to that provider — never to us, because there's no "us" here to send it to.
